# Excel生成器

这个技能帮助用户生成Excel格式的数据表格，特别适合数据库表结构、数据元素表等结构化数据的展示。

## 功能特点

- 生成标准Excel表格格式
- 支持多表结构展示
- 自动格式化列宽和样式
- 支持数据库表结构导出

## 使用方法

当用户需要将数据库表结构或其他结构化数据导出为Excel格式时，调用此技能。技能将生成可以直接复制到Excel中的表格内容。

## 输出格式

生成的Excel表格包含以下列：
- 属性名
- 数据类型  
- 长度
- 含义

每个数据库表将作为一个独立的工作表展示。
